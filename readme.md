1. How to build!
- The first, you must use git clone to clone this repo to build.
- The second, you can see, the code, I code for you the windrose app using the tkinter library. So you have to pip install the requirement in requirement.txt by the command is:
```bash 
pip install -r requirement.txt
```
If your pc have many python version, use the virtual environment like python
```bash 
python -m venv name_of_venv 
name_of_venv/Scripts/activate
```
Then, you can build file .exe using pyinstaller. If you don't have pyinstaller, please install it by command: 
```bash 
pip install pyinstaller
```
After finish the before step, next step, you can build file .exe with command:
```bash
pyinstaller app.spec
```
